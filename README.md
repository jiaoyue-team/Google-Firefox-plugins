# Google / Firefox 插件

本插件是一個開源的瀏覽器擴充功能。所有功能完全於**本地端運行**，不經過任何作者伺服器或第三方遠端伺服器，無數據收集與隱私疑慮，請放心使用。

---

## 📦 安裝方式

### 🌐 Google Chrome 安裝步驟
1. 前往擴充功能管理頁面（網址列輸入 `chrome://extensions/`）。
2. 開啟右上角**「開發人員模式」**。
3. 下載套件（建議下載最新版本）並解壓縮。
4. 在擴充功能管理頁面點擊**「載入未封裝項目」**。
5. 選擇解壓縮後的資料夾即可完成安裝。

### 🦊 Firefox 安裝步驟
- 可直接前往 Firefox Add-ons 安裝：  
  👉 [Firefox 附加元件商店連結](https://addons.mozilla.org/en-US/firefox/addon/%E7%81%AB%E7%8B%90%E4%B8%BB%E9%A1%8C/)
